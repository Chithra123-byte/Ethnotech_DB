## 📚 Learning Basic Concepts of MongoDB

This repository covers the following MongoDB fundamentals:

### 1️⃣ Writing Scripts / Queries

* Understanding MongoDB query syntax
* Using `find()` and `findOne()` to retrieve data


### 2️⃣ Insert, Delete, and Update Operations

* `insertOne()` and `insertMany()` to add documents
* `deleteOne()` and `deleteMany()` to remove documents
* `updateOne()` and `updateMany()` to modify existing documents

### 3️⃣ Aggregate Functions

* Using the **Aggregation Pipeline**
* Stages such as `$match`, `$group`, `$project`, `$sort`, and `$count`
* Performing data analysis with aggregation

### 4️⃣ Schema Design in MongoDB

* Understanding **document-based schema**
* Embedded documents vs referenced documents
* Best practices for designing MongoDB collections

### 5️⃣ Logical Operators

* Using operators like:

  * `$and`
  * `$or`
  * `$not`
  * `$nor`

### 6️⃣ Sorting and Filtering

* Filtering data using query conditions
* Sorting results using `$sort`
* Limiting and skipping results

### 7️⃣ Connecting Python to MongoDB

* Installing `pymongo`
* Connecting Python applications to MongoDB
* Performing CRUD operations using Python

### 8️⃣ Creating Arrays in MongoDB

* Storing arrays inside documents
* Querying array elements
* Updating array values using MongoDB operators
